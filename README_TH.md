# เว็บไซต์บริษัท โซลิส เอ็นเนอร์จี จำกัด

เว็บไซต์ต้นแบบใช้ HTML, CSS และ JavaScript ธรรมดา พร้อมรูปภาพโครงการที่ดึงจาก Company Profile ที่ผู้ใช้ส่งมา

## ไฟล์หลัก
- `index.html` — หน้าเว็บไซต์
- `style.css` — รูปแบบและ responsive layout
- `script.js` — สร้างรายการบริการ/ผลงาน/การรับประกัน และพฤติกรรมเมนู/แบบฟอร์ม
- `site-data.js` — ข้อมูลบริษัทและเนื้อหาที่หน้าเว็บใช้
- `admin.html` — เครื่องมือช่วยแก้ไขข้อมูลและส่งออก `site-data.js`
- `assets/` — ภาพโครงการที่มาจาก Company Profile

## ทดลองเปิด
แตก ZIP แล้วเปิด `index.html` ในเบราว์เซอร์ ภาพและฟอนต์จากภายนอกบางส่วนต้องใช้อินเทอร์เน็ต

## เผยแพร่ฟรีด้วย GitHub Pages
1. เข้าสู่ระบบ GitHub และสร้าง repository ใหม่ (เช่น `solis-energy-site`)
2. อัปโหลดไฟล์/โฟลเดอร์ทั้งหมดในแพ็กเกจ โดยให้ `index.html`, `style.css`, `script.js`, `site-data.js`, `admin.html` อยู่ระดับบนสุด และคงโฟลเดอร์ `assets` ไว้
3. เปิด `Settings` > `Pages`
4. เลือก `Deploy from a branch`, branch `main`, folder `/(root)` แล้ว Save
5. รอให้ GitHub แสดง URL เว็บไซต์ เช่น `https://ชื่อผู้ใช้.github.io/solis-energy-site/`

## วิธีแก้ไขข้อมูล
- เปิด `admin.html` ในเบราว์เซอร์เดียวกับไฟล์ชุดนี้ (หรือเปิดหน้า `/admin.html` หลังเผยแพร่)
- แก้ไขฟิลด์ทั่วไปหรือ JSON ของบริการ/แพ็กเกจ/ผลงาน/ประกัน
- กด “ตรวจสอบข้อมูล” แล้ว “ดาวน์โหลด site-data.js”
- อัปโหลดไฟล์ `site-data.js` ที่ดาวน์โหลดขึ้น GitHub โดยแทนที่ไฟล์เดิม
- รอให้ GitHub Pages เผยแพร่เวอร์ชันใหม่

**ข้อจำกัดของ Admin:** เป็นเครื่องมือสร้างไฟล์ ไม่ใช่ระบบหลังบ้านแบบหลายผู้ใช้ ไม่มีล็อกอิน ไม่มีฐานข้อมูล และไม่ได้บันทึกขึ้นเว็บไซต์โดยอัตโนมัติ ผู้ที่มีสิทธิ์แก้ repository เท่านั้นที่สามารถเผยแพร่ข้อมูลใหม่ได้

## ข้อจำกัดของแบบฟอร์มติดต่อ
แบบฟอร์มยังไม่ได้เชื่อมต่ออีเมล, LINE OA, CRM หรือฐานข้อมูล เมื่อกดส่งจะช่วยเตรียมข้อความไว้คัดลอกไปติดต่อบริษัท จึงไม่ควรโฆษณาว่าเป็นระบบรับลูกค้าอัตโนมัติ

## ข้อมูลที่ควรตรวจสอบก่อนเผยแพร่
- ตรวจสอบชื่อ/สะกดโครงการทั้งหมดและสิทธิ์การใช้รูปผลงาน
- ตรวจสอบขนาดระบบและสถานที่กับเอกสารต้นฉบับ
- เพิ่ม LINE Official Account, Facebook Page, อีเมล และลิงก์โซเชียลที่ยืนยันแล้ว
- ยืนยันชื่อรุ่นอุปกรณ์/ระยะเวลารับประกันกับใบเสนอราคาปัจจุบัน
- หน้าเว็บยังไม่มีราคาสินค้า เพราะ Company Profile ที่ใช้ไม่ได้ให้ราคาขายแพ็กเกจ


## รุ่นปรับปรุงเว็บไซต์ (Responsive + SOLIS Brand)

- ใช้โทนสีแดง/ม่วงอ้างอิงจากโลโก้ SOLIS และฟอนต์ไทยอ่านง่าย
- ปรับหน้าโครงการให้เรียงตามขนาดระบบจากมากไปน้อย และกดดูภาพ/รายละเอียดในหน้าต่างขยายได้

### วิธีอัปโหลดไป GitHub Pages
1. แตกไฟล์ ZIP นี้ในคอมพิวเตอร์
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ `solis_energy_website` ไปยังโฟลเดอร์ root ของ repository โดยต้องอัปโหลดโฟลเดอร์ `assets` ทั้งโฟลเดอร์ด้วย (อย่าอัปโหลดเฉพาะไฟล์ HTML)
3. ยืนยันว่ามี `index.html`, `style.css`, `script.js`, `site-data.js` และโฟลเดอร์ `assets` อยู่ระดับเดียวกัน
4. Commit changes แล้วเปิด `https://imm290752.github.io/solis-energy-site/` รอ GitHub Pages อัปเดต

หมายเหตุ: ตัวเลขเครื่องคำนวณเป็นค่าประมาณเพื่อวางแผนเท่านั้น ส่วนราคาชุดอุปกรณ์อ้างอิงจากภาพแพ็กเกจที่ได้รับและต้องยืนยันกับบริษัทก่อนใช้เสนอขายจริง

## การตั้งค่า Google Forms ล่าสุด
- ตั้งค่า entry IDs ที่ได้รับจากลิงก์ Pre-fill สำหรับ 6 ช่องหลักแล้ว
- ช่องแพ็กเกจที่สนใจและรายละเอียดเพิ่มเติมยังไม่ได้ตั้งค่า entry ID เพราะยังไม่มีในลิงก์ Pre-fill ที่ได้รับ
- โค้ดเว็บไซต์ส่งคำตอบไปยัง endpoint `formResponse` โดยใช้ iframe; หลังเผยแพร่ต้องทดสอบส่งคำตอบจริงและตรวจแท็บ Responses ใน Google Forms/Google Sheets ก่อนถือว่าใช้งานได้
- ลิงก์ Pre-fill ที่ได้รับมีคำตอบตัวอย่างส่วนบุคคล จึงนำมาใช้เฉพาะ ID ของช่อง ไม่ได้ใส่ค่าตัวอย่างลงเว็บไซต์
