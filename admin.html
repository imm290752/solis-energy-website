เครื่องมือแก้ไขข้อมูลเว็บไซต์ SOLIS

ใช้ปรับข้อมูลข้อความและข้อมูลโครงการ ก่อนสร้างไฟล์ site-data.js เพื่อนำไปอัปโหลดทับไฟล์เดิมใน GitHub

ข้อจำกัดสำคัญ: นี่เป็นเครื่องมือช่วยแก้ไฟล์ ไม่ใช่ระบบหลังบ้านออนไลน์ที่บันทึกขึ้นเว็บไซต์อัตโนมัติ การกดดาวน์โหลดจะสร้างไฟล์ site-data.js ใหม่ จากนั้นต้องอัปโหลดไฟล์นี้ไปยัง repository ของเว็บไซต์เพื่อให้ผู้เข้าชมทุกคนเห็นข้อมูลใหม่ ไม่มีระบบล็อกอินหรือฐานข้อมูลในต้นแบบนี้
